# Phase 4 Commercial Metadata Architecture

Phase 4 establishes one canonical metadata/commercial source of truth. Identity-critical values come from Phase 2; product-critical values come from Phase 3. KDP, IngramSpark, PNM, websites and launch assets consume mapped data rather than becoming separate authorities. Pricing/royalty/returns arithmetic is deterministic. Dynamic platform limits and rates are stored in dated rule snapshots and refreshed before live use. GATE-07 requires human approval.
