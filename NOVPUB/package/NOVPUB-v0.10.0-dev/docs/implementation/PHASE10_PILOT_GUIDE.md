# Phase 10 Real-Novel Pilot Guide

Phase 10 certifies NOVPUB against a real completed novel. It is not a fixture-only release gate.

1. Obtain/approve `GATE-NOVPUB-RC1` through real professional review.
2. Run `python novpub_cli.py init-pilot <workspace>`.
3. Establish a real manuscript baseline and SHA-256 freeze.
4. Execute NPUB-01..NPUB-76 as REAL_EXECUTED or NOT_APPLICABLE_WITH_JUSTIFICATION.
5. Run real KDP and Ingram adapter pilots; never fabricate platform/proof status.
6. Register all pilot findings and remediate release-blocking defects with regression coverage.
7. Run the same controlled pilot checks with actual Codex and actual Claude executions.
8. Obtain professional human review of the real pilot artefacts.
9. Evaluate V1-01..V1-30 and obtain human release approval.
10. Only then freeze `NOVPUB v1.0.0`.
