# NPUB-05 — Style Bible

## Purpose
Create the authoritative editorial style reference for this novel while protecting deliberate authorial style.

## Outputs
- `STYLE_BIBLE.md`
- `style_rules.json`
- `exceptions.json`

## Authority order
1. Explicit author preference.
2. Established manuscript convention.
3. Novel-specific Style Bible.
4. Chosen language/style authority.
5. General editorial convention.

## Required coverage
Language variant, spelling, names, capitalization, numbers, dates/times, punctuation, dialogue, italics, scene breaks, chapter headings, special terminology, and exceptions.

## Protected features
Support markers such as `dialect`, `intentional_fragment`, `nonstandard_capitalisation`, `character_specific_grammar`, `invented_spelling`, `stream_of_consciousness`.

## Rule
A protected style feature must not be automatically normalized merely because it differs from generic grammar/style convention.

## Human boundary
Ambiguous style choices that could affect author voice require author/editor approval.

## Exit
`STYLE_LOCKED`.
